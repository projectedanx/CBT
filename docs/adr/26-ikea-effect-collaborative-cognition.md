# ADR 26: IKEA Effect in Collaborative Cognition

## Status
Accepted

## Context
Within systems engineering, the "IKEA Effect" dictates that individuals place higher value on workflows they actively build. Top-down architectures suffer from Intent Drift. To resolve this, visual environments must be co-created, transforming abstract intents into a Shared Mental Model (SMM).

The structural paradox (Isomorphic Tension) relies on heavily constrained boundaries that provide the illusion of open-ended creation while minimizing extraneous cognitive load.

## Decision
The architecture will enforce four specification pillars for co-created workflows:
1.  **Automated Discovery and Constraint Mining:** Hard boundaries mapped to topological anomalies (Typological Drift). Soft targets optimizing the Cognitive Reynolds Number (Re) for laminar flow.
2.  **Isomorphic Formalization:** Utilizing a Context-to-Execution Pipeline (CxEP) to translate canvases directly to typed Product-Requirements Prompts (PRPs).
3.  **Parametric Trade-off Modeling:** Injecting Positive Friction when the Confidence-Fidelity Divergence Index (CFDI) exceeds 0.42 to prevent Automation Bias.
4.  **Continuous Falsification:** Implementing an Uncertainty Accelerator (Chaos Engine) to stress-test the SMM, logging failures to the Scar Tissue Archive (STA).

## Method of Exploration
We implemented:
-   **Chrono-Topological Tracker:** Utilizing Topological Data Analysis (TDA) to calculate Zigzag Persistence Homology over sequential visual collaboration intervals.
-   **Speculative Abstract Interpretation Engine (SAIE):** Compiling visual canvases into Domain-Specific Languages (DSL) and verifying safety properties.
-   **Chaos Engine:** Systematically injecting Epistemic Pathogens (Concept Drift, Instrumental Convergence, Semantic Ambiguity) to test resilience limits.

## Consequences
-   Reduces Semantic Ossification by optimizing the "Goldilocks Zone" of constraints versus user agency.
-   Mathematically links visual layout anomalies (disconnected components $b_0$ and persistent loops $b_1$) to interpretive fracture.
-   Validates the necessity of Epistemic Escrow when chaos-engineered tests push CFDI past bounds.
